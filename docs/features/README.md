# Features

Une fiche par feature ajoutée après le scaffold initial. Format `NN-feature-slug.md` — le préfixe numérique garde l'ordre chronologique.

Chaque fiche contient :
- **But** — ce que la feature fait
- **Fichiers touchés / ajoutés**
- **Backend** — nouveaux modules, commandes, threads, champs d'état
- **Frontend** — nouveaux events, UI, payloads
- **Comment tester** — check concret côté utilisateur
